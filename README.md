# 宝雀（ポージャン）β

開始画面の「CPUの難易度」で「ノーマル」（初期値）と「本気」を選べます。難易度は対戦表示・結果・履歴に記録します。人数、交換、ベット、ショーダウンのルールは共通です。

開始画面のキャラクター画像と対局中のNPCの顔画像は、クリック／タップすると全身画像をポップアップで大きく表示します。閉じるボタン、枠外の背景のクリック、Escapeキーで閉じられます。画像にキーボードでフォーカスしてEnter／Spaceでも開けます。ランダムの「?」は拡大対象ではありません。

## 総合結果をXに投稿

ローカルでHTMLを直接開いた場合は、結果画像の準備時だけ `js/result-portraits.js` を読み込み、Base64化したNPCの顔画像を使ってPNGを書き出します。GitHub Pagesでは通常の画像ファイルを使用します。顔画像を差し替えた場合は `node scripts/build-result-portraits.cjs` でBase64データも更新してください。データ読み込み失敗などで画像の書き出しが制限された場合は、画像を省いた結果を保存できます。PCの共有先にXがない場合は、PNGを保存し、文章入りのX投稿画面で画像を添付してください。共有先の一覧はOSと共有先アプリが決定します。

総合結果の「画像を保存」は順位・名前・最終所持点・NPCの顔画像・指定タグをまとめたPNGを出力します。保存操作後は画像プレビューも表示し、iPhoneなどでダウンロードできない場合は画像を長押しして保存できます。「画像付きで共有」は対応ブラウザの共有メニューに画像と結果文を渡します。Xなどの共有先は利用者が選び、文章と画像の引き継ぎは共有先アプリの対応によります。非対応・共有失敗時は保存用プレビューを表示します。共有キャンセル時には自動保存しません。外部サービスへの自動投稿は行いません。

対戦終了後（第四場完了、または持ち点0点以下）の総合結果に「総合結果をXに投稿」を追加しています。プレイヤーの名前・対戦人数・総合順位・最終所持点と、`#宝雀 #宝雀ランキング` を入れたXの投稿画面を別タブで開きます。投稿内容はX上で確認・編集でき、投稿の確定は本人が行います。オンラインランキングへの登録やデータベースへの送信は行いません。

## 対局アニメーション

SEはタップ終了・クリック・キー操作で有効化します。iPhone向けに無音サンプルで音声出力を準備し、音声が停止・中断している場合は再開します。再開完了前の効果音は直近1件だけを最大1秒保持し、古い音や画面を離れる前の音はまとめて再生しません。

プレイヤーとNPCのツモ時にカードが中央方向から手札へ入り、打牌時に捨て札へ滑り込む演出を表示します。ツモ・ロン成立時は勝者の手札が明るく光り、成立の文字が拡大して現れます。演出中も操作・手番は進行し、カード選択や役の切り替えでは演出を再生し直しません。端末の「視差効果を減らす」など動きを抑える設定に従います。Web Animations APIに対応していないブラウザでは演出を省略します。

対局中のNPCの顔画像は従来の縦横2倍（84×84px）です。ツモ・ロン成立時の役名ボタンにカーソルを重ねると、「役と遊び方」と同じ成立条件をブラウザ標準の説明表示で確認できます。開始画面の「対戦を始める」ボタンは、キャラクター画像枠の直下に配置しています。

`index.html` をブラウザで開いてください。サーバーの起動、インストール、ビルドは不要です。

HTML・CSS・JavaScript・画像を分割しています。移動や共有の際は、`index.html` と `css`・`js`・`picture` を同じフォルダー構成のまままとめて扱ってください。画像の更新は `picture` 内の同名ファイルを置き換えるだけで反映できます（表示中のページは再読み込みしてください）。

## 遊び方と現在の仕様

- 開始画面で2人・3人・4人対戦を選びます。2人対戦は「ランダム」（初期値）またはスィリス、桃桃（タオタオ）、甘美音カナデから相手を選べます。3人・4人対戦は重複なしのランダム選出です。対戦相手は第四場まで固定です。NPC登録機能はありません。
- 4枚配牌から開始し、各巡で1枚引いて交換します。役ができた手札でストップでき、最終巡はドロー後に自動でストップします。ストップ後も手番ごとに1枚引いて捨て、手札を固定します。相手の捨て札で役ができる場合はロンしてカードを手札に加え、ストップします。規定交換数は人数別の巡数と同じです。
- 手札は数字優先／スート優先で自動整列します。スート順はダイア、ルビー、サファイア、エメラルドです。
- 全員ストップまたは規定交換数終了後にベットします。チェック、1000点ベット、1000点刻みのレイズ、コール、フォールド、オールインができます。オールイン後の未対応者はコールかフォールドを選びます。
- 2～4人対戦すべて全員25000点で開始します。各場は人数分の局で終了し、持ち点をリセットせず次の場へ引き継ぎます。第四場終了、または誰かの持ち点が0点以下になった時点でゲーム終了です。0点ちょうどでも終了します。
- ショーダウンでは役の強さ、手札の最大数字、その数字のスート（ダイア＞ルビー＞サファイア＞エメラルド）の順で比較します。役順はペアシェイプ、トリリアント、キャッツアイ、トライゴン、カラーレス、フローレス、フォーダイト、アステリズム、4C、ブリリアントです。同順位はポットを均等分配し、端数はディーラーからの手番順です。オールインのポットは参加額ごとに分けて精算し、誰もコールしなかった超過分は返します。全員フォールド時はポットを分配せず次局へ持ち越します。
- 場名はスペースオブダイアモンド、スペースオブルビー、スペースオブサファイア、スペースオブエメラルドです。
- 勝利点は使用しません。対戦終了時の最終所持点だけで順位を決め、同点は同順位です（例：1位・2位・2位・4位）。各場の持ち点を合算して順位を決めることはありません。
- SE設定はプレイヤー枠の下にあり、初期音量は75%。ブラウザの最初のクリック／キー操作後に音が有効になります。
- 完了した対戦の成績とニックネームをブラウザ内に保存します。進行途中のゲーム保存と外部通信は行いません。

## ニックネームと対戦履歴

開始画面のニックネーム欄に20文字以内で入力し「登録」を押します。未入力は「あなた」です。「対戦を始める」でも入力中の名前を登録します。名前は対局中と最終結果に表示されます。

第四場完了または持ち点0点以下による終了時に、終了日時、対戦人数、ニックネーム、対戦したNPC、全員の各場の所持点・順位、最終所持点・総合順位を自動記録します。途中で開始画面へ戻ったゲームは記録しません。名前を後から変更しても、過去の成績の名前は変わりません。

開始画面の「対戦履歴」で過去の各場・総合結果を確認できます。結果画面の開き直しでは重複保存しません。履歴はこのブラウザのlocalStorageを使い、同じブラウザ・同じ保存領域で再読み込みすると復元します。HTMLを移動した場合の扱いはブラウザによって異なり、別の端末やブラウザには自動共有されません。

「JSONでバックアップ」または結果画面の「記録をJSONで保存」から、ニックネームと全履歴をファイルとして保存できます。ブラウザ内データを削除すると履歴も消えるため、残したい成績はJSONも保存してください。JSONの再取り込み機能はありません。

容量不足やブラウザ設定で保存できない場合は、その旨を表示して一時的に画面内で保持し、JSONバックアップを利用できます。保存済みデータが壊れて読み込めない場合は上書きしません。

## NPCごとの打ち筋

| NPC | 特徴 |
|---|---|
| スィリス | 連番と広い待ちを好む速攻型 |
| 桃桃（タオタオ） | ペア・3カードを育てる攻撃型 |
| 甘美音カナデ | 絵札・ドラを重視し、捨て札から守備も考える慎重型 |

2人対戦のキャラ選択時に特徴を表示します。NPCは自分の手札と公開情報を使って交換・ストップ・ベットを選び、他の手札はショーダウンまで参照しません。

評価式、特徴量、守備の推定、設計上の制約は [NPC行動選択設計書](docs/NPC_AI_DESIGN.md) にまとめています。

## テスト

Node.jsがある環境で、作業フォルダーから次を実行します。

```text
node tests/run.cjs
```

個別の確認には `node tests/test_match.cjs` のように実行します。外部ファイルの配置・読み込み順、全役と倍率、点数、整列、SE、手札表示、ダブルタップ、4場の集計を確認します。従来の200場と50ゲーム（各4場）に加え、3人・4人それぞれ100ゲーム（各4場）の自動対戦を実行します。

`tests/test_player_records.cjs` はニックネームと成績の再読込、2～4人分の保存、重複防止、過去の名前の保持、途中終了、JSON出力、保存失敗、壊れた保存データの保全を確認します。

分割後も全テストが成功しています。画面のテストには簡易DOMを使っており、実ブラウザでの表示・音の確認は含みません。

元の設計書は開発開始時点の資料です。その後の変更については、このREADMEと実装を参照してください。

## NPCの台詞

各NPC枠内に、ゲーム開始時、ショーダウン勝利、ドロー、第四場終了時の勝利・敗北の台詞を表示します。勝利台詞には成立した最上位の役名が付きます。

台詞の編集は `js/npc-dialogue.js` で行います。テキスト表示であり、音声読み上げはありません。`tests/test_npc_dialogue.cjs` で各NPCのイベント・役名・表示の保持と解除を確認できます。

開始画面のNPC選択枠と総合結果枠では、枠内の右側に `picture/名前_full.png` を大きく表示します。名前に添える小さな画像は使用しません。対局中のNPC枠右側は `picture/名前_face.png` を表示します。対応表は `js/assets.js` の `NPC_FULL_IMAGES` と `NPC_FACE_IMAGES` です。

## 人数別の対局ルール

| 対戦人数 | NPC人数 | 1場の局数 | 最大巡数 |
|---|---|---|---|
| 2人 | 1人 | 2局 | 8巡 |
| 3人 | 2人 | 3局 | 5巡 |
| 4人 | 3人 | 4局 | 4巡 |

巡数は2人戦8、3人戦5、4人戦4です。親は局ごとに手番順で交代します。ショーダウン勝者がポットを受け取り、同順位の場合は均等分配します。全員フォールド時のポットは次局へ持ち越します。第四場完了または誰かの持ち点が0点以下で終了し、各場の点数と最終順位を表示します。

オールイン発生後、未対応のプレイヤーはコールまたはフォールドを選びます。全員が対応した後にショーダウンします。

人数別の配牌、巡数、親交代、全NPCのロン判定、見送り、得点移動、台詞、最終順位、手番タイマーは `tests/test_multiplayer.cjs` で確認します。

## コンパクトな卓レイアウト

4人対戦はプレイヤーを下、次の手番のNPCを左、その次を上、最後を右に配置します。親の席から時計回り（下→左→上→右）に行動します。中央は場・局・巡・親・ドラ・山札だけを表示します。3人は下→左→右、2人は下→上です。左右のNPCの手札・捨て札は90度回転し、左はカードの上端が右へ、右は左へ向く形で中央を挟んで向かい合います。名前・台詞・役の説明は正立表示です。

プレイヤーの手札は52×72px、NPCは34×48px、捨て札は20×28pxを基本とし、以前の大型表示から縮小しました。対局中のNPCの顔画像は手札の右側に小さく表示します。操作ボタンは使えるものだけをプレイヤー枠の右側に表示します。狭い画面では卓の周囲配置を保ち、卓部分を横スクロールできます。

絵札は10＝星（`10_star.png`）、11＝月（`11_moon.png`）、12＝太陽（`12_sun.png`）、13＝時計（`13_time.png`）のシンボル画像を表示します。数字と現在の場の宝石スートも表示します。

卓レイアウトを変更する際は、共通スタイルの後に読み込む `css/table-layout.css` を編集してください。画面の人数別クラスは `js/ui.js` が切り替えます。

プレイ画面下部の「開始画面へ戻る」は対戦途中でも使えます。戻ると対戦を終了し、待機中のNPC処理を無効化します。開始画面から再び始めると新しいゲームになります。

対局終了時は最後の手札と役を表示したままにし、総合結果は自動で開きません。対局枠の「総合結果」を押すと画面中央に重ねて表示します。「対局画面を見る」またはEscapeキーで閉じられ、「開始画面へ」で新しいゲームを始められます。結果表示中は背景の対局操作を無効にします。

開始画面は左側に人数選択と「ランダム＋NPC3人」の縦4段ボタンを置き、右側の共通プレビューへ選択したNPCのfull画像を大きく表示します。ランダム選択時と3・4人対戦では「?」を表示します。ボタン内には画像を置きません。

場名の横には対応するダイア・ルビー・サファイア・エメラルドの画像を表示します。対局情報、場の終了案内、総合結果・保存済み履歴の場名に適用します。旧形式の履歴は読み込み時に勝利点を除去し、最後の場の所持点から順位を再計算します。

新ルールの進行は `js/poker-rules.js`、役と最大数字の比較は `js/hand-evaluator.js` で管理します。

## ショップ・戦績・実績画面

開始画面の「ショップ」「戦績」「実績」ボタンで、それぞれの専用画面へ移動します。各画面の「開始画面へ戻る」で対戦設定に戻れます。

- ショップ：GP残高、27種類のGSの購入（軽100・中200・重300 GP）、装備・解除（合計3枠）、GP獲得・購入履歴。
- 戦績：総対戦回数、人数別勝利数、最大所持点、NPC別勝利数。人数・難易度で絞り込め、対戦履歴の詳細とJSONバックアップもここから確認できます。
- 実績：NPCへの初勝利の達成状況と、購入済みGSの種類数・収集割合。

2人対戦で単独勝利すると100 GP、各NPCへの初勝利では追加300 GPを獲得します。購入・装備後の残高や収集状況は各画面へ反映されます。

GS枠は対局卓内でプレイヤー枠と同じ幅に配置します。カード・数字・スートの選択肢はカード表示です。「GS使用をキャンセル」またはEscapeキーで、通常ツモへ進む前のGS使用を取り消せます。カード配置と使用回数も使用前に戻ります。通常ツモへ進んだ後、ロン判定中、局終了後には取り消せません。

GSによる引き直し・交換・保管・山札への返却にもカード移動のアニメーションを表示します。「視差効果を減らす」などの設定時は演出を省略します。

開始画面の「データを削除してはじめから」を押すと確認を表示します。確定するとニックネーム、対戦履歴・戦績、実績、GP、購入・装備GSを初期化し、所持100 GPで再開します。キャンセル時は変更しません。保存処理に失敗した場合は初期化できなかった旨を表示します。

ショップは「手札／山札／情報」のタブでGSの種類を切り替えます。占い師は `picture/shop.png`、種類別キャラクターは手札＝`skill_hand.png`、山札＝`skill_stock.png`、情報＝`skill_wisdom.png` を使用します。タブはクリックのほか、左右矢印・Home・Endキーでも切り替えられます。

重GSは対応するNPCへの本気モードでの単独1位の履歴があるとショップへ表示します。手札＝スィリス、山札＝タオタオ、情報＝カナデ。2～4人対戦の完了記録が対象で、3・4人対戦は該当NPCが参加した対戦で単独1位が条件です。同率1位・難易度不明の旧記録は対象外です。以前に購入済みのGSは引き続き表示・装備できます。


## 順位報酬・実績報酬と装備枠拡張

順位報酬は2人対戦1位100 GP、3人対戦1位200・2位100 GP、4人対戦1位300・2位200・3位100 GP。本気モードの順位報酬は2倍です。2人対戦の同率1位は従来どおり対象外、3・4人対戦の同率順位は表示順位に対応する額を受け取ります。途中離脱は対象外で、持ち点0以下による決着は完了対戦として対象です。

実績報酬は各1回、固定額です。完了対戦1回で100 GP、10回で300 GP、100回で500 GP。本気モードで各NPCに初単独勝利すると各500 GP、全NPCに達成すると追加500 GPとGS装備枠4を獲得します。既存の2人対戦NPC初勝利300 GPも維持します。3・4人対戦で単独1位なら、その対戦に参加した各NPCへの本気勝利として記録します。

過去の記録で達成済みの新実績は読み込み時に一度だけ解除・付与します。過去の順位報酬を新料金で再計算して差額付与することはありません。結果画面とGP履歴で順位報酬・実績報酬の内訳を確認できます。

GSの付け替えは開始画面の「GSを付け替える」またはショップの「購入済みGSから付け替える」で行えます。装備枠のGSを押すと外れ、空き枠を押すと選択欄が開きます。枠不足時は外すGSを複数選び、変更後の枠数を確認して一度に入れ替えられます。確定前のキャンセルでは装備は変わりません。「すべて外す」も利用できます。

開始画面は補足説明を省き、対戦設定・NPC選択・装備をコンパクトに表示します。ショップのGP獲得方法は、画面右上の「開始画面へ戻る」の隣にある「ヘルプ」で確認できます。ヘルプには順位報酬、本気モードの倍率、実績報酬、獲得対象・対象外の条件をまとめています。閉じるボタン・背景クリック・Escapeキーで閉じられます。
